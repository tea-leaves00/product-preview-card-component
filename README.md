### What I learned

I learned a lot from this project. Kevin Powell actually goes through this particular challenge on Youtube. I had already completed the challenge, so I just watched his video afterwards and compared what I could have done better. For example, I learned about using custom properties inside of containers (e.g. `--padding: 1rem;`) and then utilizing this custom property inside of the contents of the container (e.g `padding: var(--padding);`). This makes it much more reusable and prevents you from having to go back and hunt through your stylesheet to find out where random padding is coming from.

I also learned some new semantic HTML elements to use such as `<data>` and `<s>`. This was also my first time using the BEM naming convetion for classes, which made reusing components much more maintainable.

### Continued development

I think my flexbox skills still need sharpening. I tend to mix different properties such as width or max-width, rather than using conventions such as the flex shorthand.

I also would like to start trying out a mobile-first approach with some of these challenges, as I think it makes creating responsize layouts easier.
